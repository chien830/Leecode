# Top K Frequent Elements

## 题目思路

给定一个数组 `nums`，要求返回出现频率最高的前 `k` 个元素。

核心思路：

1.  使用哈希表统计每个元素出现的次数。
2.  将哈希表中的数据转换为 `vector<pair<int,int>>`。
3.  按照 `pair` 的第二个元素（出现频率）进行降序排序。
4.  取排序后前 `k` 个元素。

------------------------------------------------------------------------

## 代码

``` cpp
class Solution {
public:
    vector<int> topKFrequent(vector<int>& nums, int k) {

        vector<int> result;

        unordered_map<int,int> hash;

        // 统计元素出现次数
        for(int i=0;i<size(nums);i++)
        {
            hash[nums[i]]++;
        }

        // 哈希表转换为vector<pair<int,int>>
        vector<pair<int,int>> v(hash.begin(),hash.end());

        // 按照频率降序排序
        sort(v.begin(), v.end(),
            [](const auto& a, const auto& b) {
                return a.second > b.second;
            }
        );

        // 取前k个高频元素
        for(int j=0;j<k;j++)
        {
            result.push_back(v[j].first);
        }

        return result;
    }
};
```

------------------------------------------------------------------------

# 哈希表转换

`unordered_map` 本身不能直接排序，因此需要转换：

``` cpp
vector<pair<int,int>> v(hash.begin(),hash.end());
```

例如：

    hash:

    元素     出现次数
    1        3
    2        2
    3        1

转换后：

    v:

    {
        {1,3},
        {2,2},
        {3,1}
    }

其中：

    pair.first  -> 元素
    pair.second -> 出现次数

------------------------------------------------------------------------

# sort函数

## 基本形式

``` cpp
sort(first, last, compare);
```

三个参数：

  参数      含义
  --------- --------------
  first     排序开始位置
  last      排序结束位置
  compare   排序规则

------------------------------------------------------------------------

## 自定义排序规则

形式：

``` cpp
sort(begin, end,
    [](元素类型 a, 元素类型 b){
        return 排序规则;
    }
);
```

第三个参数决定：

> a 和 b 两个元素比较时，谁应该排在前面。

例如：

``` cpp
return a < b;
```

表示：

    a较小 -> a在前

即升序。

``` cpp
return a > b;
```

表示：

    a较大 -> a在前

即降序。

------------------------------------------------------------------------

# 本题排序规则

``` cpp
[](const auto& a, const auto& b) {
    return a.second > b.second;
}
```

因为：

    pair.first  = 数字
    pair.second = 出现次数

所以比较：

``` cpp
a.second > b.second
```

表示：

    出现次数大的元素排在前面

即按照频率降序排列。
